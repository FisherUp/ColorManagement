# 环氧磨石颜色管理系统

这是一个面向销售、工厂配色人员、销售助理的颜色主数据与下单确认前端原型。

## 技术路线

- React
- Vite
- lucide-react

## 本地运行

当前环境无法解析 `registry.npmjs.org`，所以依赖尚未安装。网络可用后运行：

```bash
npm install
npm run dev
```

## 免安装预览

可直接用浏览器打开：

```text
prototype.html
```

静态预览页用于查看视觉结构和关键业务流程；完整交互版本在 `src/App.jsx`。

## 已实现的核心原型

- 项目侧边栏筛选
- 项目详情与案例图片区
- 颜色清单表格
- 套装 Item Code 与 A 组分 Item Code 区分展示
- 下单单位固定为“套”
- 易混淆颜色人工标记提醒
- 非可用状态限制提示
- 下单确认单
- CSV/Excel 可打开格式导出
- 导出留痕展示
